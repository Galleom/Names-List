Ever thought you didn't had enough name options for your baby/character? Well, fear no more for I've compilated tens of thousands of them for you, lol

Basically, this was done by running a python script that goes through the US National data on baby names, removing repeats and separating by gender. "Neutral" names were acquired by running one list against the other and listing repeats between them.

It was done automatically so some errors may be present and the limitions of the database itself also apply (such as it needing at least 5 entries)

Some statistics for you:

There are 13930 unique male names

There are 17297 unique female names (~25% more names)

There are 2589 unique gender-neutral names

There's a total of 28638 unique names overall

(~48% male, ~60% female, ~9% neutral)
